# Plantillas XSLT

En esta carpeta se colocan las hojas XSLT proporcionadas por la SEP.

## Certificados (DEC)

- **Archivo:** Copiar aquí el XSLT del apartado "Código fuente" del documento de especificaciones técnicas.
- **Nombre sugerido:** `CertificadoElectronico.xslt` o el que indique la SEP.
- **Uso previsto:** Transformar el XML del certificado (elemento raíz `Dec`) a HTML para vista previa o impresión.

Ver: `backend/docs/CERTIFICADOS_XSD_Y_XSLT.md`
